II) Variables
---------------
  * A variable is a named memory location used to store data that can be accessed and manipulated during program execution.
  * The value stored in a variable can be reused, changed, or updated during program execution.

rules:
 * Can start with letters, _ , $
 * Can't start with numbers
 * No reserver Keywords. Built-In Keywords like this, for, let, while, etc...
 * Case-Sensitive (Age != age)
 * Camel-Case must be used
i.e: valid= let userName; let _count; let $price;
     invalid = let 1name; let let; let for

X = 10
'X' is variable,'10' is data
studentName = "Adolf"
'studentName' is variable,'Adolf' is data

Use keywords to declare variable: (var, let, const)

Syntax: keyword variable :datatype = value
i.e. var age :number = 30
i.e. var age = 30

1) Var, Let, Const:
* Var: not recommended,outdated.function scoped and lead to unexpected issues.(i.e. loop, conditonal statements)
* let: use when you need a varible that can change values.
* const: use when you need a varible that won't change or shouldn't change values.
