 Array:
  * Array is a data structure used to store multiple values in a single variable.
  * Array can hold the same data type or different Data types.
  * Arrays are declared using '[ ]' symbol or generic keyword 'array<type>'.
  * Index value of the first element in an Array starts from 0 and the last element value (n-1), if 5 is last index then (5-1)
  * Arry is an ordered collection of elements, the order how the values are stored.

Syntax:
  Method 1: First declaration then assigning value.
  * let names: string [] = [];
    names[0] = 'John';
    names[1] = 'Johnson';
    names[2] = 'Sam';
    names[3] = 'Ram';
     console.log(names);
  Method 2: Declaration with assigning value.
  * let empId: number[] = [1221, 2332, 3443, 4554];
     console.log(empId);

Tuple:
 * Tuple is a fixed length of array, were each elements has a specific type.
 * Tuple helps in storing multiple fields of different data types together.
 * Tuples are stricter than regular arrays.
Syntax:
       * variable : [type1, type2] = [value1, value2]  ------> type is the placeholder of index value (type1=value1) = (variable[0])
       * variable : [type1, type2];
	  variale : [value1,value2]
Tuple with two values with type
 * let newData:[number,string] = [45,'Andrew'];
   console.log(`Mr.${(newData[1])} is ${(newData[0])} years old.`)

Tuple with multiple values with type: (fixed data type for index)
 * let newData:[number, string, boolean, string, number] = [45,'Andrew', true, 'Alice', 43];
   console.log(`${(newData[0])} years old ${(newData[1])} is ${(newData[2])}ly going to marry ${(newData[3])} who is ${(newData[5-1])} years old`);
