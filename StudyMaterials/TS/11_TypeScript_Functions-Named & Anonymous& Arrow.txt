    TypeScript - Function - Named , Anonymous & Arrow
--------------------------------------------
 * Function is a block of code designed to perform a specific task.
 * Function is a block of code which we can reused.
 * Function is used to call whenever we need to reuse in code.
-------------------------------------------------------------------------

Named / Anonymous / Arrow Functions:

Named Function:
  * A function that is declared with a name is named functon.
  * Named function should hava a name followed by function keyword.
  Syntax: function functionName(parameter): returntype
	    {
	      block of code
	    }

	  functionName (argument); 
 1 - function - keyword
 2 - functionName - name of the function we used to invoke.
 3 - parameter - it act as a placeholders for the values/Argument the function will receive later. single or multiple parameters can be passed.
 4 - returntype - if the function rturns a value we have to mention the type or type inference will take. if there is no return we can mention void. 
 5 - { block of code } - single or multiple statements that should be executed when we call the function.
 6 - functionName (argument)- How we call or recall the functon, to invoke the function.
 7 - (argument) - The actual values passed to the function when it is called that we need to execute in the block of code

Anonymous/Nameless Function:
   * Anonymous Function are also know as Nameless function or Unnamd function
   * The function that does not have a name.instead, it is assigned to a variable, which act as its name.
   * All the functions seen in the Named function can be used as Anonymous/Nameless function
   Syntax: let variable = function(parameter):
	    {
	      block of code
	    }

	  variable (argument);
 i.e. * let fun = function (morning: string): void 
         {
	   console.log(morning);
         };
	fun ("good Morning");
      * let optional = function (...element: (number|string) []): number
         {
           return element.length;
          }
         console.log(optional ('john',23,25,'solomon',22,28));

Arrow/Lambda Function:
  * Arrow function are part of anonymous functions.
  * they doesn't have a name and can be stored into a variable.
  * All the functions seen in the Named function can be used in Arrow/Lambda function
Syntax: let variable = (parameter) => 
         {
	  block of code
	   }
	variable ();

	=> : it called as 'goes to operator'
 i.e. * let fun =(morning: string): void =>
