 Methods:
  * Methods are built-in functions in programming Language that let you perform operations on data.
  * All methods are functions, but not all functions are methods because method belongs to an object
  * Methods ends with () .
 String:
  * string is a text value or a group of characters (abcd, fruit, etc....).
  * string should be mentioned in single quotes(' '), double quotes(" "), backtick(` `).
  * string values are Case sensitive ( Apple, apple - are not the same).
  * string is immutable, the value cannot be changed after it is created.
    * You cannot modify the original string
    * Any operation that seems to change it, actually creates a new string.
  * Index value of the first element in string starts from 0

Index Access:
 * string.charAt(index No.) - retrive the value at the index.
 * string.indexOf(string) - retrive the index of the value of first Occurence.
 * string.indexOf(string,7) - 7 the first ocurrence afteer the 7th index.
 * string.lastIndexOf(string) -  - retrive the index of the value of Last Occurence.
 * string.substring(starting index, ending index -1) - gets values between the indexes.
     console.log("Value at 6th index: ",name.charAt());
     console.log("Value at 7th index: ",name.charAt(7));
     console.log("Value at 40th index: ",name.charAt(40));
     console.log("index of N Upper Case: ",name.indexOf('N'));
     console.log("index of N Lower Case: ",name.indexOf('n'));
     console.log("index of 'holding' starts from: ",name.indexOf('holding'));
     console.log(name.substring(19,26));

Value Verify: (returns Boolean: true/false)
 * string.includes('value') - verifies the value exists in String.
 * string.startsWith('value') - verifies the String is starts with the value.
 * string.endsWith('value') - verifies the String is Ends with the value.
     console.log("string includes 'hold': ",name.includes('hold'));
     console.log("string includes '!': ",name.includes('!'));
     console.log("string includes '!': ",name.includes('!',5)); ---> search after index
     console.log("string starts with 'AbRaHaM': ",name.startsWith('AbRaHaM'));
     console.log("string starts with 'Abraham': ",name.startsWith('Abraham',4)); 4 ----> index value
     console.log("string ends with 'A': ",name.startsWith('A'));
     console.log("string ends with '!': ",name.endsWith('!',5)); 5 ----> length of the string
     console.log("string ends with 'phone...!': ",name.endsWith('phone...!'));
