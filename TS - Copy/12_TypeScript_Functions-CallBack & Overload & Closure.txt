Call-Back Function:
  * A callback is a function passed as an argument to another function so that it can be executed later, either after a task completes or when a specific event occurs.
  * It is commonly used in asynchronous programming and event handling.
 Syntax: function func1(cb: any)  -------> passing function as argument into another function.

Callack Hell / Pyramid Of Doom:
    Callback Hell is a programming pattern where multiple asynchronous callbacks are nested inside one another, resulting in deeply indented, hard-to-read, and difficult-to-maintain code. It is commonly avoided by using Promises or async/await.

Closure Function:
 * A closure function is a function that remembers and can access variables from its outer (parent) function even after the outer function has finished executing.
Method 1:
function myVariable (){
    let a = 25;
    let b = 57;
    function maths(){
        let c = a*b;
        console.log(c);
    }
    return maths;
}
let value1 = myVariable(); 
value1 ();

Method 2:
 function outer() {
   let count = 0;
   function inner() {
     count++;
     console.log(count);
   }
   return inner;
 }
 const counter = outer();

 counter(); // 1
 counter(); // 2
 counter(); // 3
