Interface:
 * Interface in Typscript is a way to define the structure of an object.
 * It is like a blueprint for Object.
 * It specifies what properties and methods an object should have, along with their types.
 * you can't skip properties until it is optional property.
 * Can rearrange the properties. but, what mentioned in the Interface it must be in Objects.
 * similer to class but class cantains properties, constructor, Method, while interface contains properties, methods.
 * Abstract Method: we only signature of the method. there is no implementation, ths implementation must be in the child classes
--------------------------------------------------------------------------------------------------
syntax:
 interface intefaceName {
 properties
 methods
}
let newInterface: intefaceName= {key='value', key1= value}

Class, Interface:
extends = inherit structure/behavior
implements = provide implementation

 Possible:
   Class Extends Class  --> A class inherits properties and methods from another class.
   Interface Extends Interface  --> One interface can inherit members from another interface.
   Class Implements Interface  --> A class provides the implementation for an interface.
   Interface Extends Class --> An interface can extend a class. The interface inherits the instance members (properties and methods) of that class.
    
 Impossible:
   Interface Implements Class  --> *implements means "provide implementation".
				   *Interface cannot provide implementation.
				   *Interface only declares structure.

Class vs Interface:
  Class:
    Denition:
	Bluprint to create Objects with implementation.
    Contains:
	Properties, Constructors, Methods. (with implementation)
    Instatiation:
	Can be instantiated using (new) Keyword.
    Inheritance:
	Supports single Inheritance using (extends) keyword.
    Implements:
	A class can implement one or more Interfaces.
    Modifiers:
	Supports Access modifiers (public, private, protected).

  Interface:
    Denition:
	Defines structure/type of an Object with no implementation
    Contains:
	Only Properties and methods (without implementation)
    Instatiation:
	Cannot be instantiated directly.
    Inheritance:
	Supports multiple Inheritance using (extends) keyword.
    Implements:
	Interface cannot implement a Class.
    Modifiers:
	Does not support Access modifiers

Modules:
 A MODULE in TypeScript is a file that exports codes (contains variables, Functons, Interfaces, Classes, Types, etc..) and allows other files to import it. 
  * Module is simply a file that contains code you can export and reuse in other files.
  * Modules help you organize code into seperate files and avoid global scope pollution.
  * Modules prevent naming conflicts by keeping declaration in their own scope.
